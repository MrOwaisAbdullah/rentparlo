## Affiliate Referral Program

### How It Works:
1. Every seller receives a unique referral code upon registration
2. Share your referral code with friends, family, or on social media
3. When someone uses your code to sign up, both you and the new user receive benefits

### Referral Benefits for Sellers:
- **For the referrer:** PKR 100 credit towards your next subscription payment for each successful referral
- **Tier Bonuses:**
  - Bronze tier sellers: 5% bonus on referral earnings
  - Silver tier sellers: 10% bonus on referral earnings
  - Gold tier sellers: 15% bonus on referral earnings
  - Platinum tier sellers: 20% bonus on referral earnings
  - Diamond tier sellers: 25% bonus on referral earnings

### Referral Benefits for New Users:
- **For the referred user:** 
  - Basic Package users: Extended trial period (additional 14 days)
  - Pro Package users: 15% discount on first month
  - Premium Package users: 10% discount on first month + one free featured listing
  - Business Package users: 10% discount on first month + two free featured listings

### Additional Referral Rewards:
- Refer 5 users: Free month of current package
- Refer 10 users: 20% discount on next renewal
- Refer 20 users: Free month of next higher package tier
- Top 3 referrers monthly: Exclusive RentParlo.pk merchandise

### Affiliate Code Features:
- Sellers can create custom affiliate codes
- Codes can offer percentage discounts (5-20%) or fixed amount discounts
- Usage limits and time restrictions can be set
- Performance tracking for each code
- Commission calculations based on referred user activity

## Package Management

### Upgrading:
- Upgrade anytime through your seller dashboard
- Prorated charges for the remainder of your billing cycle
- Immediate access to upgraded features

### Downgrading:
- Downgrade at the end of your current billing cycle
- No refunds for remaining time on current package
- Loss of features associated with higher-tier package

### Cancellation:
- Cancel anytime through your seller dashboard
- Access to paid features continues until end of billing cycle
- Downgraded to Basic package automatically after cancellation

## Billing Information

### Payment Methods:
- Credit/Debit cards (Visa, Mastercard)
- JazzCash
- Easypaisa
- Bank transfer

### Billing Cycle:
- Monthly subscriptions renew on the same date each month
- Yearly subscriptions (10% discount) renew annually
- Payment reminders sent 3 days before renewal

### Refund Policy:
- 7-day money-back guarantee for new subscriptions
- No refunds for partial months of service
- Refunds processed within 5-7 business days
